# Projeto Exemplo - Comparador de Números

## Descrição
Este programa em Python permite comparar dois números inteiros introduzidos pelo utilizador e indicar se são iguais ou diferentes. Inclui validação de entrada para garantir que apenas números inteiros são aceites.

## Funcionalidades
- Comparação de dois números inteiros
- Validação de entrada de dados
- Mensagens claras de resultado

## Instruções de Utilização

### Requisitos
- Python 3.x instalado
